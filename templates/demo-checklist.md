# {{PROJECT_NAME}} — demo checklist

## Before recording

- [ ] The demo path works from a clean start.
- [ ] The useful result appears within 45 seconds of the demonstration starting.
- [ ] Known-good sample input is in `demo/sample-input/`.
- [ ] Any useful fallback output is in `demo/sample-output/`.
- [ ] Text is readable at 1080p without squinting.
- [ ] Notifications, personal messages, API keys, tokens, email addresses, and unrelated tabs are hidden.
- [ ] Microphone level is clear and not clipping.
- [ ] Project/system audio is audible if the project needs it.
- [ ] Biscuit Logic branding mode is `{{BRAND_MODE}}` and allowed by the hackathon.
- [ ] The spoken script has been read aloud once.

## OBS

- [ ] Scene: `Biscuit Demo`.
- [ ] 1920×1080, 30 fps.
- [ ] Record to MKV.
- [ ] Biscuit Logic tag sits bottom-right and does not cover controls or output.
- [ ] A 20-second test recording has been watched back.

## During recording

- [ ] Start with the project already ready to demonstrate.
- [ ] Say what it is immediately.
- [ ] Show input → action → output.
- [ ] Explain only one interesting technical idea.
- [ ] Finish cleanly. Do not trail into installation notes or apologies.

## Before submission

- [ ] Remux/export to MP4 if required.
- [ ] Watch the final file from beginning to end.
- [ ] Confirm video duration fits the hackathon rules.
- [ ] Confirm audio works in the exported file, not only in OBS.
- [ ] Confirm no secrets or private information appear frame-by-frame.
- [ ] Keep the raw recording until the submission is accepted.
